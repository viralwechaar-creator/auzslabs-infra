Android apps

Download the AUZslab apps.

Every AUZslab app, straight to your phone — no Play Store account needed. These open the real, live website inside the app, so you always see the newest version the moment it ships.

Before you install

These are direct APK files, not from the Play Store, so Android will warn "Install blocked" or "Unknown source" the first time — that's expected. Tap Settings in that warning, allow your browser to install unknown apps, then install again. These are test builds: expect occasional rough edges, and update to a newer build whenever one is released.
