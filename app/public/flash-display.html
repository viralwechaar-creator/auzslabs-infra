Flash the customer display

For a brand-new (or blank) Waveshare ESP32-S3-LCD-2.8 board only. An already-flashed board updates itself automatically over WiFi — see Settings → Customer-facing screen in AUZsStyle instead.
This browser can't talk to USB devices. Open this page in Chrome or Edge (desktop or Android) instead.

Before you start

1
Get the .merged.bin file for this firmware — produced once by compiling firmware/customer-display/AUZLAB_Display_Test.ino in Arduino IDE (Sketch → Export Compiled Binary). Look in the sketch's build output folder for a file ending in .merged.bin. If there isn't one, see this page's note at the bottom.
2
Plug the board into this computer's USB port. Close Arduino IDE's Serial Monitor if it's open (it locks the port).
3
Pick the file below, then press Flash. A browser prompt will ask you to choose the USB device — pick the one listed (often "USB JTAG/serial debug unit").

If Arduino IDE didn't produce a .merged.bin

      
Older Arduino-ESP32 core versions export three separate files instead
        (*.bootloader.bin, *.partitions.bin, plain *.bin) —
        this page only supports a single merged file today. Update the "esp32" board package in
        Arduino IDE's Boards Manager to a recent version (it then exports the merged file
        automatically), or ask for this page to be extended to support the three-file case.
